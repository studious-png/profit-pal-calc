# The Liquidation Matrix

Risk-based position sizing and liquidation calculator for high-leverage crypto trading.

## Stack

- Vite
- React + TypeScript
- Tailwind CSS
- lucide-react

## Local Development

```bash
npm install
npm run dev
```

## Build and Lint

```bash
npm run build
npm run lint
```

## White-Label Branding

This project supports fast rebranding for Option A (friend uses their own GitHub + Vercel).

See:

- `BRANDING.md`
- `src/branding.ts`

Your friend can rebrand by editing one config file and deploying their own fork.
